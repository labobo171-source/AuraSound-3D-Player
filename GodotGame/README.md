# Street Brawler — Godot 4 starter

This starter project is stored in the AuraSound-3D-Player repository in the `GodotGame/` folder.

**Status:** starter scaffold, not yet run or verified in Godot.

## Open the project
Open Godot 4.x and import this folder's `project.godot` file.

## Files
- `project.godot`: project settings
- `scenes/Main.tscn`: main scene
- `scripts/main.gd`: background, spawning, HUD, score
- `scripts/player.gd`: movement and basic attacks
- `scripts/enemy.gd`: simple enemy chase/attack

Keyboard: arrows/WASD for movement, Space/Enter for attack. Special action requires a filled meter (prototype).

No engine testing or Android APK build has been performed yet.
